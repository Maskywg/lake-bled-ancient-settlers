# 溯源卡尼奧拉：布萊德湖與斯洛維尼亞阿爾卑斯原始居民演變特別研究
### Prehistoric to Early Medieval Inhabitants of Lake Bled & Upper Carniola (Gorenjska)

這是一個結合**考古學、人類學、古遺傳學（Ancient DNA）與 GIS 互動地圖**的數位策展專題網頁，深度解析布萊德湖與斯洛維尼亞阿爾卑斯山區（上卡尼奧拉 / Gorenjska）五萬五千年以來的四大關鍵族群演變地層：

---

## 🏛️ 四大族群歷史地層

1. **舊石器時代（約 5.5 萬年前）**
   - **尼安德塔人（Neanderthals）**：出土全人類已知最古老樂器——**迪夫耶貝貝骨笛（Divje Babe Flute）**。
   - **早期智人（克羅瑪儂人）**：波托奇卡洞穴（Potočka zijalka）高山洞熊狩獵與奧瑞納文化（歐洲最古老骨針）。
   - **考古證據鏈**：莫斯特石器工業、放射性地層測年、微地層人工用火爐灶與屠宰割痕。

2. **新石器至銅石並用時代（西元前 5000–2000 年）**
   - **湖泊水上木樁文化圈（Pile Dwellers / Mostiščarji, UNESCO）**：歐洲原初狩獵採集者（WHG）與安納托利亞農耕先民（EEF）的融合。
   - **世界最古老木製輪軸（5,200 年前）**：盧比亞納沼澤 Stare Gmajne 出土。
   - **布萊德湖島開發**：整木刳製獨木舟（Deblaki）與湖心庇護所。

3. **鐵器時代（西元前 4 世紀–西元 1 世紀）**
   - **凱爾特部族**：**卡爾尼人（Carni）**與 **陶里斯奇人（Taurisci）**。
   - **地名活化石**：斯洛維尼亞核心省名**「卡尼奧拉（Carniola / Kranjska）」**與名城**「克拉尼（Kranj / Carnium）」**字源考證。
   - **高山冶鐵與信仰**：諾里克鋼（Ferrum Noricum）、瓦切青銅坐壺（Vače Situla）、布萊德島水神 Belenus 湖心聖所。

4. **西元 6 世紀斯拉夫大遷徙與基因融爐**
   - **斯拉夫人（Slavs）進駐**：與在地殘存的羅馬化凱爾特居民深度混血與雙向文化同化。
   - **神話與信仰演變**：布萊德島愛神芝娃（Živa）神廟（後改建聖母堂）與三頭神（Triglav）聖山。
   - **現代基因庫解析**：古斯拉夫 R1a (38%) + 凱爾特 R1b (21%) + 古巴爾幹 I2a (22%) + 地中海農民 (15%)。
